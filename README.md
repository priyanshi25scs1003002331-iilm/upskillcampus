# Quiz Game & Performance Analysis System

A Python-based Quiz Game and Performance Analysis System developed as part of the **UpSkillCampus Python Internship**.

The project allows users to select a quiz topic, answer multiple-choice questions, calculate their performance, visualize their results, and analyze previous quiz attempts.

## Features

- Topic-based quiz selection
- 30 multiple-choice questions
- 3 topics:
  - Python
  - Pandas
  - NumPy
- 10 questions per topic
- Answer validation
- Automatic score calculation
- Percentage calculation
- Performance classification
- NumPy-based statistical analysis
- Quiz performance visualization using Matplotlib
- Quiz result storage using Pandas
- Overall performance analysis
- Simple menu-driven interface

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- CSV
